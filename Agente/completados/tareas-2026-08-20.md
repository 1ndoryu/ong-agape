  con 3 posts de ejemplo basados en el contexto real de El Proyecto Ágape (sopas
  comunitarias, visitas, alianzas; tono transparente y humano). El contenido vive en la
  base de datos (migración seed) y el frontend lo consume vía la API pública
  `/api/blog` — no hay contenido hardcodeado en el componente.

    CONFLICT (slug) DO NOTHING` (sopa-comunitaria-barcelona, visitas-que-acercan,
    alianzas-que-suman) con `created_by/updated_by` NULL (no hay usuarios todavía).
  - `migrations/20260820000000_seed_blog_example.down.sql` — `DELETE` por slug.
  - `frontend-v2/src/features/inicio/BlogInicio.tsx` — componente de la sección
    `#blog`: fetch a `/api/blog` con `AbortController`, estados cargando/error/vacío/

    {dateStyle:'long'})`, lista horizontal de hasta 3 tarjetas con

    lista.
  - `frontend-v2/src/features/inicio/BlogInicio.css` — estilos con tokens del sistema
    (rojo/azul/amarillo/lino), lista horizontal con `overflow-x: auto`, `scroll-snap`
    y scrollbar oculta (la tercera tarjeta asoma por el borde), tarjetas grandes
    (`min(88vw, 400px)`), enlace "Leer historia" como botón píldora
